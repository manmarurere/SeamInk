SeamInk（シームインク）― FF14 肌テクスチャ用 タトゥー転写ツール
=====================================================================

3Dの体の上に透過PNGを貼るだけで、肌テクスチャの正しい場所へタトゥーを書き込むツールです。

肌テクスチャは、体が「左右」「上半身と下半身」などいくつかの部品に分かれて並んでいるため、
おへそや背中の中心のように継ぎ目をまたぐ柄は、手作業だと分割して描く必要がありました。
SeamInk は 3D の体から逆算して書き込むので、継ぎ目をまたいでもつながった柄になります。

起動すると、あなたの Penumbra の設定を読んで、今ゲームで使っている
「体のモデル（上半身・下半身）」と「肌テクスチャ」を自動で読み込みます。


■ 必要なもの
--------------------------------------------------
- Windows 10 / 11
- XIVLauncher（Dalamud）と Penumbra
- 体と肌を mod で入れていること
  （Bibo+ / RueXB / YAB+ / X-Body Skin などの体・肌 mod。バニラの体・肌には対応していません）
- Python 3.8 以上
  https://www.python.org/downloads/ からインストールしてください。
  インストール画面の最初で「Add python.exe to PATH」に必ずチェックを入れてください。
- Chrome または Edge
- 起動時のインターネット接続（3D 表示の部品を読み込みます）


■ 同梱ファイル
--------------------------------------------------
  Start_SeamInk.bat   … これをダブルクリックして起動します
  seamink.html        … ツール本体
  seamink_server.py   … Penumbra の設定と mod を読むための小さなプログラム（読み取り専用）
  README_ja.txt       … このファイル
  README_en.txt       … 英語版の説明

同じフォルダに置いたまま使ってください。


■ はじめての起動
--------------------------------------------------
1. zip で受け取った場合は、先に「すべて展開」してから使ってください。
   （zip の中から直接ダブルクリックすると動きません）
2. 「Start_SeamInk.bat」をダブルクリックします。
   「Windows によって PC が保護されました」と出た場合は、
   「詳細情報」→「実行」を押してください。
3. 黒いウィンドウが開き、少しするとブラウザで SeamInk が開きます。
   黒いウィンドウはツールを使っている間、閉じずにそのままにしてください。
4. 画面左上の「Penumbraで使用中の体を読み込む」で、
   自分のキャラの「種族」と「性別」を選んで「読み込む」を押します。
   体と肌が表示され、どの mod のどのファイルを読んだかが下に出ます。
   次回からは、起動するだけで自動で読み込みます。
5. 画面の言語は、左上の「日本語 / English」で切り替えられます。
   画面の「使い方」を開くと、操作の説明が読めます。


■ 使い方
--------------------------------------------------
1. タトゥー画像を追加する
   「3 タトゥー」に透過 PNG を入れるか、3D の画面に直接ドロップします。
   ドロップした場所に貼られます。何枚でも重ねられます。

2. 位置と大きさを合わせる
   体の上を左ドラッグすると、タトゥーが体の表面に沿って移動します。
   サイズ・回転・濃さはスライダーで調整します。

     体を左ドラッグ ……… タトゥーを移動
     背景を左ドラッグ …… 視点を回す（Alt+ドラッグなら体の上でも回せます）
     右ドラッグ …………… 視点の平行移動
     ホイール ……………… ズーム
     Shift+ホイール ……… タトゥーの大きさ
     Ctrl+ホイール ……… タトゥーの回転
     Q ……………………… 配置モードのオン・オフ
     Delete ………………… 選んでいるタトゥーを削除

   正面・背面・左側・右側のボタンで視点を切り替えられます。
   右下の「テクスチャ上の位置」で、柄がテクスチャのどこに書かれるかを確認できます。

3. 保存する
   「合成テクスチャを .tex で保存」を押すと、ブラウザのダウンロードフォルダに
   「（元の名前）_tattoo.tex」が保存されます。
   画面に「差し替え先」として、置き換えるべき mod 内のファイルの場所が表示されます。

4. ゲームに反映する
   (1) 差し替え先のファイルを、別の場所にコピーしてバックアップします。
   (2) 保存した _tattoo.tex の名前を、差し替え先のファイル名と同じに変えて上書きします。
   (3) Penumbra でその mod を一度無効にしてから有効に戻します。
       見た目が変わらない時は、チャットで /penumbra redraw を実行するか、ゲームを再起動してください。

   元に戻すときは、バックアップしたファイルを書き戻してください。
   ※ その mod を更新・再インストールすると、タトゥーは消えます（元のファイルに戻ります）。


■ 便利な機能
--------------------------------------------------
- 投影の厚み …… 柄が腕・股・背中側にはみ出す時は小さくします
- 回り込み限界 … 体の側面にどこまで回り込ませるか。小さいほど正面だけに写ります
- 視点方向から投影 … 今見ている向きからまっすぐ貼ります
- 左右対称コピー …… 体の反対側へ鏡写しで複製します
- 単色 …………… 画像を1色で塗ります（黒い線画の色替えに）
- 重ね方「乗算」 … 肌の陰影が透けて、なじみやすくなります
- 配置を保存 / 開く … タトゥーの画像と位置をファイルに残し、あとで続きから編集できます
- タトゥーだけ（透過PNG）… 画像編集ソフトで自分で重ねたい人向け


■ 安全について
--------------------------------------------------
- 読み取り専用です。Penumbra の設定や mod のファイルを書き換えることはありません。
  （ゲームへの反映は、上の手順で自分でファイルを置き換えます）
- 読むのは Penumbra の設定ファイルと、mod フォルダ内の .mdl / .mtrl / .tex / .png だけです。
- 通信は自分の PC の中（127.0.0.1）だけで、画像やファイルを外部に送ることはありません。
  インターネットには、3D 表示の部品（three.js）と画面の文字フォントを読み込みに行くだけです。


■ うまくいかないとき
--------------------------------------------------
● 黒いウィンドウに「Python 3.8 以上が見つかりません」と出る
  → Python をインストールしてください（「Add python.exe to PATH」にチェック）。
    インストール後は PC を再起動するか、一度サインアウトしてから試してください。

● 黒いウィンドウは開いたが、ブラウザが開かない
  → 黒いウィンドウに表示されている http://127.0.0.1:〜 のアドレスを、
    Chrome か Edge に貼り付けて開いてください。

● 「Penumbraの設定フォルダが見つかりません」
  → XIVLauncher 以外の場所に Penumbra の設定がある場合は、コマンドプロンプトで
      Start_SeamInk.bat --penumbra "…\pluginConfigs\Penumbra のフォルダ"
    のように指定して起動してください。

● 「体のモデルを入れ替えるmodが見つかりません」「肌の素材がmodで見つかりません」
  → 選んだ種族・性別で、体や肌を入れ替える mod が Penumbra で有効になっていません。
    ・種族と性別の選択が、自分のキャラと合っているか
    ・体・肌の mod が Penumbra で有効になっているか
    ・下の「設定」で、自分のキャラに使っているコレクションが選ばれているか
    を確認してください。バニラ（mod なし）の体・肌には対応していません。

● 体の上で肌の柄がずれて見える
  → 「1 体のモデル」の「UVの上下を反転」を切り替えてください。

● 3D の画面が真っ暗・何も表示されない
  → インターネットにつながっているか確認して、ブラウザを再読み込みしてください。
    それでも出ない場合は、Chrome / Edge を最新版にしてください。

● 黒いウィンドウが一瞬で消える
  → コマンドプロンプトを開き、SeamInk のフォルダで Start_SeamInk.bat を実行すると、
    エラーの内容が読めます。


■ 制限
--------------------------------------------------
- バニラの体・肌には対応していません。
- 書き出す .tex は無圧縮（B8G8R8A8）です。4K の肌だと 1 ファイル約 89MB になります。
- 体の細かい部分（股間など、テクスチャ上でとても小さい場所）は、柄が少しにじみます。
